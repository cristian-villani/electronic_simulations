Electronic Simulations - Arduino Projects

Welcome! This repository contains small Arduino experiments demonstrating embedded programming and interaction with analog circuits. These projects are designed for learning and didactic purposes.

Frequency Generator & RC High-Pass Filter

Arduino-based square wave generation with a potentiometer-controlled frequency, filtered with a simple RC high-pass filter. Includes Tinkercad simulation and oscilloscope screenshots.

Resonance and LC Oscillator Simulation

LC oscillations and resonance with an interactive Arduino-driven circuit. Visualize charge/discharge cycles, sweep excitation timing to find resonance, and analyze peak voltages.

Ultrasonic Distance Measurement

This experiment demonstrates distance measurement using an ultrasonic sensor. The Arduino triggers the sensor, measures echo timing, converts it into distance, and reacts using simple control logic.
