Ultrasonic Distance Measurement with Arduino

This project demonstrates how an Arduino can measure distance using an ultrasonic sensor (e.g. HC-SR04) by timing the echo of a sound pulse. The experiment focuses on digital timing, signal interpretation, and simple embedded control logic.

Learning goals:
  • Generate and measure microsecond-scale digital pulses
  • Convert timing information into physical distance
  • React to sensor input using embedded logic

Measurement Principle

The Arduino sends a short trigger pulse to the ultrasonic sensor. The sensor emits an ultrasonic burst and raises the echo pin HIGH for the duration of the round-trip travel time.

The pulse width is measured using pulseIn() and converted into distance: 

distance (cm) ≈ duration (µs) / 58

Behavior

  • Measured distance is printed to the Serial Monitor
  • An LED turns ON when the distance is below a fixed threshold (e.g. 70 cm)
  • Distance changes can be observed live in the simulation

Simulation

This experiment was developed and tested using Tinkercad Circuits, which allows full simulation without physical hardware.

Technical Notes

  • pulseIn() provides microsecond-resolution timing
  • No ADC is required; all signals are digital
  • Floating-point values are printed using Serial.print() due to AVR limitations
  • Simulation approximates real-world ultrasonic behavior

Limitations

  • Speed of sound assumed constant (no temperature compensation)
  • Measurement precision limited by timing resolution
  • Not suitable for very fast or very long distances

Didactic Intent

This project is intentionally simple and transparent. It demonstrates a complete sense → compute → act loop and highlights common constraints encountered in embedded systems programming.
